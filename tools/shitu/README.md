# 拾圖｜GitHub Pages 體驗版 v0.3.0

可用：IndexedDB 原圖／縮圖儲存、SHA-256 去重、批次上傳、套圖排序、收藏、可恢復垃圾桶、人工標籤／描述、文字與情境同義詞搜尋、JSON 原圖備份與合併還原。12 張原創 SVG 範例可隱藏。

此版以 GitHub Pages 靜態部署，**尚未連接 Zenfone 10、AI 視覺辨識、向量 API 或跨裝置同步**。範例搜尋來自內建描述與標籤，不代表已完成 AI 語意辨識。自己的圖片需先補名稱／描述／標籤。所有圖片只存目前瀏覽器，不上傳 GitHub。清除網站資料或無痕結束可能遺失，請匯出備份。

單張最多 25 MB、40 MP；一次最多 100 張。備份原圖上限約 100 MB，匯入最多 1,000 張，先完整驗證再原子合併；重複原圖不覆蓋既有人工內容。GIF 原圖保留，縮圖為靜態。

開發：`node --test tests/core.test.mjs`、`python3 build.py`。`dist/index.html` 是無外部依賴的單檔成品，可放在任何 GitHub Pages 子目錄。既有手機後端計畫維持獨立；此版先供操作測試。

安全：拒絕使用者 SVG、HTML 及外部 URL 備份，所有使用者文字經轉義；不使用外部追蹤、字型、圖片或模型 API，不存 API 金鑰。下載原圖與備份皆為瀏覽器本機 Blob。
